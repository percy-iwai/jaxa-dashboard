# 宇宙関連予算ダッシュボード

JAXA 調達情報（FY2019〜FY2024）と行政事業レビュー 宇宙関連事業の可視化ダッシュボード。

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## タブ構成

| タブ | 内容 |
|------|------|
| 🚀 JAXA契約実績 | JAXA 調達情報 DB（36,153件）— 年度別推移・企業分析・契約方式・データ閲覧 |
| 📋 行政事業レビュー 宇宙関連 | 文科省・内閣府・総務省・経産省の宇宙関連事業 — 支出先サンコー図・予算推移 |

## データソース

| ファイル | 内容 | サイズ |
|----------|------|--------|
| `data/db/jaxa_procurement.db` | JAXA 調達情報（会計法公表データ） | ~17 MB |
| `data/review_space.db` | 行政事業レビュー 宇宙関連（rssystem.go.jp） | ~0.3 MB |

## 出典

- JAXA 調達情報: 宇宙航空研究開発機構 公開調達情報（会計法に基づく公表データ）
- 行政事業レビュー: 内閣官房行政改革推進本部 行政事業レビュー見える化サイト（rssystem.go.jp）
